These four options are build-time toggles (Bazel --config= flags), not runtime flags — so "on/off of symmetric column ID sampling" means two separate builds. node_id_drsw + scattered histogram + smem split update are the same in both; only --config=symmetric_proj is added/omitted.

Build


bazel build //examples:oblique_apply_projection_main \
  --config=bfs_only --config=use_gpu --config=verbose_depth \
  --config=node_id_drsw --config=nid_srdw_hist \
  --define=split_smem=true

Symmetric column ID sampling OFF (just drop that last config — OFF is the default):
bazel build //examples:oblique_apply_projection_main \
  --config=bfs_only --config=use_gpu --config=verbose_depth \
  --config=node_id_drsw \
  --config=offsets_only --config=scattered_label_hist \

Symmetric column ID sampling ON (add --config=symmetric_proj):

  --config=node_id_drsw \

Notes on each piece:
- --config=node_id_drsw → the DRSW persistent node-ID strategy.
- scattered histogram → --config=scattered_label_hist, which requires --config=offsets_only (and node_id_drsw) — enforced in training.cc:5888-5897.
- smem split update → --define=split_smem=true (this is the default; passing it explicitly keeps it ON. The alternative is --config=split_global_atomic, which sets it false).
- symmetric column ID sampling → --config=symmetric_proj ON / omit for OFF. There's no =false alias.
